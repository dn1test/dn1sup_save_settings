# Changelog (Лог изменений)

Лог изменений **DN1Sup Save Settings** (`dn1sup_save_settings`).
Формат версий соответствует правилам `MAJOR.MINOR.PATCH`.

## [0.18.0] — 2026-10-27

### DN1Sup Save Settings (v0.18.0)
- **Без автоматической перезагрузки.** Сброс больше не закрывает SketchUp
  сам (таймер `Sketchup.quit` удалён), отложенное применение больше не
  запускает его снова (`relaunch` всегда `false`). В баннере активной задачи —
  кнопка «Закрыть SketchUp» (новый экшен `quit_sketchup`): пользователь сам
  решает, когда закрыть, затем открывает SketchUp вручную. Галочка
  «Запускать SketchUp после применения» удалена из окна восстановления
  и настроек расширения (настройка `restore_relaunch` удалена).
- **Жёсткая блокировка до перезагрузки.** Пока отложенная задача активна
  (`pendingActive`), запрещены создание копии, восстановление, удаление,
  импорт, смена папки архивов и сброс — разрешены только «Закрыть SketchUp»,
  «Отменить», просмотр и закрытие диалога. Ruby отклоняет повторный
  `restore_backup`/`reset_target` до применения или отмены.

## [0.17.0] — 2026-10-27

### DN1Sup Save Settings (v0.17.0)

  Дубль переключателя вида вверху удалён.

## [0.16.0] — 2026-10-27

## [0.15.0] — 2026-10-26

### DN1Sup Save Settings (v0.15.0)
- **История по версиям SketchUp + перенос между версиями.** Правая панель
  показывает блоки SketchUp 2024 / 2025 / 2026 (текущая помечена): копии,
  созданные в других версиях, видны сразу и восстанавливаются в текущую
  одной кнопкой — архив ищется и в чужом хранилище, пути `local/roaming`
  ложатся на текущие каталоги. У чужой копии — бейдж «из 2024» и
  предупреждение в окне восстановления (расширения другой версии могут быть
  несовместимы). Пустые годы — свернутые блоки «сохранений нет».
  Новый модуль `version_stores.rb` (сканирование чужих `history.json` +
  orphan-zip по манифесту, дедуп общей кастомной папки), тесты
  `version_stores_test.rb`.
- **Учёт разницы хранения настроек и расширений.** Окно восстановления:
  выбор путей галочками (можно вернуть только настройки интерфейса без
  плагинов), подсказки совместимости у каждого пути, красное предупреждение
  со списком нативных бинарников (`.so`/`.dll` из лога архивации —
  `Archiver.scan_native`), отдельный раздел справки про перенос между
  версиями и честная оговорка про реестр Windows (не сохраняется).
- fix: повтор копирования при `EACCES`/`EPERM` (антивирус лочит свежие файлы
  в staging) — до 3 попыток с паузой вместо падения бэкапа/восстановления.
- fix: ошибка загрузки в SketchUp 2024 (`Could not find included file
  'dn1sup_save_settings/dn1sup_updater'`): стартовый загрузчик на отсутствие
  файла апдейтера отвечает исключением мимо `rescue LoadError/StandardError`.
  Теперь сначала `File.file?`, затем `rescue Exception` (апдейтер опционален).
- fix(test): guard от повторной загрузки `test_helper.rb` — второй прогон
  через `ext_test` в одной сессии больше не даёт `SystemStackError`.
- fix: помощник отложенного применения ждал закрытия ВСЕХ процессов SketchUp
  по имени — восстановление в 2024 висело, пока открыты 2025/2026. Теперь ждёт
  только экземпляры той же установки (сравнение по пути `.exe`); каждая задача
  несёт уникальный `armed_id`, при повторном arm!/arm_reset! старый helper
  тихо выходит вместо двойного применения.
- **Вкладки версий вместо блоков.** У каждой версии SketchUp своя вкладка:
  слева — её настройки (у текущей — сохранение галочками, у остальных —
  пути на чтение), справа — её история. Ruby отдаёт состояние 7 путей для
  каждого года (`VersionStores.targets_for_year`); по умолчанию открыта
  текущая версия. Внутри вкладки версии — подвкладки «Настройки» и «История
  сохранений» (выбор запоминается); общие настройки расширения (папка
  архивов, галочка автозапуска после восстановления через новый экшен
  `set_restore_relaunch`, сведения) — за кнопкой-шестерёнкой в шапке.
  Список истории вынесен в компонент `HistoryList.vue`, общие форматтеры —
  в `historyUtils.js`. Кнопка создания копии с комментарием живёт в шапке
  подвкладки «История» (текущей версии), выбор путей — в «Настройках».

## [0.13.1] — 2026-10-15

- Исправлено падение резервной копии `Errno::EACCES @ rb_file_s_symlink`,
  если в сохраняемых папках (например `Plugins/asm_faceup`) есть
  симлинки/джанкшны: `Archiver` копирует их разыменованным содержимым, а не
  пересоздаёт ссылки через `File.symlink` (на Windows это требует привилегии
  `SeCreateSymbolicLinkPrivilege`). Битые ссылки и циклы пропускаются с
  предупреждением в журнале и строкой в логе архивации.
- То же разыменование применено при восстановлении (`Restorer.copy_over!`).
- Тест: симлинк-каталог/файл попадают в архив содержимым, битый пропускается.
- Интерфейс: убрана дублирующаяся кнопка «Обновить сведения» в шапке
  (два одинаковых значка подряд) — сведения и так обновляются из Ruby
  после каждой операции; остались проверка обновлений, справка и тема.
