# Changelog (Лог изменений)

Лог изменений **DN1Sup Save Settings** (`dn1sup_save_settings`).
Формат версий соответствует правилам `MAJOR.MINOR.PATCH`.

## [0.14.8] — 2026-10-17

### DN1Sup Save Settings (v0.14.8)
- **Обновление — только из GitHub.** Кнопки проверки и фоновая проверка при
  старте переведены с `check_local_first!` на `check!`; `dev_dir` удалён из
  манифеста. Копия общего апдейтера обновлена до v5 (единая копия для всех
  расширений DN1Sup: локальные источники удалены, для менеджеров старых
  версий оставлены заглушки совместимости, status_cb-прогресс сохранён).
## [0.14.7] — 2026-10-16

### DN1Sup Save Settings (v0.14.7)
- **Фирменная плитка DN1Sup в шапке GUI** — та же плитка, что в каталоге
  Extension Store (цветной квадрат, знак с «воздухом»); работает в светлой
  и тёмной теме. Источник — `dn1sup_extensions` (`tools/make_icons.rb`).
## [0.14.6] — 2026-10-16

### DN1Sup Save Settings (v0.14.6)
- **Фирменный знак тулбара DN1Sup** — единый стиль каталога Extension
  Store: ползунки настроек (slate), прозрачный фон, вырезы — настоящая прозрачность
  (SVG-маска; PNG 16/24 — альфа-канал). Источник знака —
  `dn1sup_extensions` → `icons/products/` (`tools/make_icons.rb`).


## [0.14.5] — 2026-10-16

- fix: добавлены недостающие `icons/ss_16.png` и `icons/ss_24.png`
  (fallback для SketchUp < 16 в `setup_toolbar` — раньше лежал только
  `ss.svg`, старые версии оставались без иконки). Дизайн не менялся:
  PNG отрисованы новым генератором `tools/make_icons.rb` по тому же SVG
  (синяя дискета, белая шторка, зелёный zip-бейдж).

## [0.14.4] — 2026-10-16

- fix(dev): `update_from_dev.rb` говорил с мостом dn1sup_mcp2 по HTTP
  POST /eval, а мост понимает только TCP newline-JSON — всегда врал
  «мост не запущен». Hot Reload переписан на `Socket.tcp` +
  `{"cmd":"eval"}`.

## [0.14.3] — 2026-10-16

- Убран переходный маркер `.sketchup_dev.json` из `dev_source?` (период
  миграции со старых `_dev`-установок завершён); self-update рабочей копии
  определяется только по пути загрузки (вне папки Plugins).

## [0.14.2] — 2026-10-15

- Кнопка проверки обновлений в шапке показывает выполнение: при нажатии
  иконка крутится, повторные нажатия блокируются, всплывает тост
  «Проверка обновлений на GitHub…». Итог проверки приходит нативным
  диалогом SketchUp, спиннер снимается по таймауту.

## [0.14.1] — 2026-10-15

- Проверка обновлений по кнопкам — только GitHub-релиз: кнопка в шапке
  диалога и пункт меню «Проверить обновления сейчас» вызывают
  `Dn1sup::Updater.check!` вместо `check_local_first!` (локальная папка
  разработки больше не проверяется и не предлагается к установке).
- Тултип кнопки в шапке — «Проверить обновление на GitHub».

## [0.14.0] — 2026-10-15

- При создании резервной копии теперь видно, что происходит: окно прогресса
  показывает текущий шаг («Копирование: Расширения (Plugins) (3/6)»,
  «Упаковка zip-архива…») и шкалу выполнения.
- Сборка идёт пошагово (по одной цели за шаг), интерфейс не висит монолитно:
  между шагами окно успевает перерисоваться.

## [0.13.1] — 2026-10-15

- Исправлено падение резервной копии `Errno::EACCES @ rb_file_s_symlink`,
  если в сохраняемых папках (например `Plugins/asm_faceup`) есть
  симлинки/джанкшны: `Archiver` копирует их разыменованным содержимым, а не
  пересоздаёт ссылки через `File.symlink` (на Windows это требует привилегии
  `SeCreateSymbolicLinkPrivilege`). Битые ссылки и циклы пропускаются с
  предупреждением в журнале и строкой в логе архивации.
- То же разыменование применено при восстановлении (`Restorer.copy_over!`).
- Тест: симлинк-каталог/файл попадают в архив содержимым, битый пропускается.
- Интерфейс: убрана дублирующаяся кнопка «Обновить сведения» в шапке
  (два одинаковых значка подряд) — сведения и так обновляются из Ruby
  после каждой операции; остались проверка обновлений, справка и тема.

## [0.13.0] — 2026-10-15

- Удалён функционал dev/prod (второй id `dn1sup_save_settings_dev`): удалены
  `DEV_BUILD`, поле `dev_build` в состоянии диалога и бейдж DEV в шапке.
  Разработка — рабочая копия под тем же id («Обновить из рабочей копии» /
  reload); self-update рабочей копии отключён по пути загрузки
  (`Dn1sup::Updater.dev_source?`); файлы `.sketchup_dev.json` удалены.
- Добавлена кнопка проверки обновлений в шапке диалога: сначала проверяется
  локальная папка, затем GitHub.
- Убраны dev-кнопки обновления из рабочей копии и hot reload (чистка
  диалога, main и UI).
- Единый апдейтер v3 (`shared/dn1sup_updater.rb`), поле `author` в
  `registry.json`; удалён `tools/inspect_rbz.rb`.
- CI: тело релиза собирается из CHANGELOG.md (`tools/release_body.rb`).
