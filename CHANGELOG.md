# Changelog (Лог изменений)

Лог изменений **DN1Sup Save Settings** (`dn1sup_save_settings`).
Формат версий соответствует правилам `MAJOR.MINOR.PATCH`.

## [0.14.0] — 2026-10-15

- При создании резервной копии теперь видно, что происходит: окно прогресса
  показывает текущий шаг («Копирование: Расширения (Plugins) (3/6)»,
  «Упаковка zip-архива…») и шкалу выполнения.
- Сборка идёт пошагово (по одной цели за шаг), интерфейс не висит монолитно:
  между шагами окно успевает перерисоваться.

## [0.13.1] — 2026-10-15

- Исправлено падение резервной копии `Errno::EACCES @ rb_file_s_symlink`,
  если в сохраняемых папках (например `Plugins/asm_faceup`) есть
  симлинки/джанкшны: `Archiver` копирует их разыменованным содержимым, а не
  пересоздаёт ссылки через `File.symlink` (на Windows это требует привилегии
  `SeCreateSymbolicLinkPrivilege`). Битые ссылки и циклы пропускаются с
  предупреждением в журнале и строкой в логе архивации.
- То же разыменование применено при восстановлении (`Restorer.copy_over!`).
- Тест: симлинк-каталог/файл попадают в архив содержимым, битый пропускается.
- Интерфейс: убрана дублирующаяся кнопка «Обновить сведения» в шапке
  (два одинаковых значка подряд) — сведения и так обновляются из Ruby
  после каждой операции; остались проверка обновлений, справка и тема.

## [0.13.0] — 2026-10-15

- Удалён функционал dev/prod (второй id `dn1sup_save_settings_dev`): удалены
  `DEV_BUILD`, поле `dev_build` в состоянии диалога и бейдж DEV в шапке.
  Разработка — рабочая копия под тем же id («Обновить из рабочей копии» /
  reload); self-update рабочей копии отключён по пути загрузки
  (`Dn1sup::Updater.dev_source?`); файлы `.sketchup_dev.json` удалены.
- Добавлена кнопка проверки обновлений в шапке диалога: сначала проверяется
  локальная папка, затем GitHub.
- Убраны dev-кнопки обновления из рабочей копии и hot reload (чистка
  диалога, main и UI).
- Единый апдейтер v3 (`shared/dn1sup_updater.rb`), поле `author` в
  `registry.json`; удалён `tools/inspect_rbz.rb`.
- CI: тело релиза собирается из CHANGELOG.md (`tools/release_body.rb`).
